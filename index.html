How to play

⌨️

Move

↑ ↓ ← → or WASD. On phones, swipe on the board or use the D-pad.

Food

Each apple is worth 10 × level points and grows the snake by one.

Golden bonus

Appears now and then for a few seconds. Grab it for 50 × level points.

🚀

Level up

Every 5 apples raises the level — the snake gets faster and points get bigger.

⏸

Pause

P or Space pauses. M mutes sound. Enter restarts.

💀

Game over

Hitting your own tail ends the run — and the walls too if "pass through walls" is off.

About

Snake dates back to the 1976 arcade game Blockade and became a worldwide hit on mobile phones in the late 1990s. This version is built with plain HTML, CSS and JavaScript — no frameworks, no build step — so it's a great project to read, remix and learn from.
